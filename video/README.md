# Missing Blue: intro video

The 97-second English intro for Missing Blue (AI Quest 2026, Al Hussein Technical University, Sector 02), made with [Remotion](https://www.remotion.dev/) (React → MP4).

The finished video ships with the app as `public/video/missing-blue-intro.mp4`. Everything needed to re-render it is in this folder, including the narration, music, sound effects, imagery and fonts.

## Render it

```bash
cd video
npm install
npm run render
```

This writes `out/missing-blue.mp4` (1920×1080, 30 fps). The first render downloads Remotion's headless Chrome, about 120 MB.

To scrub through it in the browser:

```bash
npm run studio
```

To render one frame:

```bash
npx remotion still MissingBlue out/frame.png --frame=1300
```

## How it is put together

| Path | What it is |
|---|---|
| `src/Video.tsx` | Timeline: scenes, narration, music ducking, sound effects, light leaks, competition badge |
| `src/scenes.tsx` | The 11 scenes: AI Quest ident, Jordan, water loss, attacks, records, logo reveal, Detect, Verify, Remember, proof, close |
| `src/map.tsx` | Jordan outline (Natural Earth), the illustrative carrier line, leak particles, attack pings, satellite scan |
| `src/kit.tsx` | Colours, fonts, easing, word-by-word text, counters, grain, backdrop |
| `src/timeline.json` | Frame timings, generated by `tools/timeline.py` from the narration clips |
| `public/audio/` | Narration (`vo_XX.wav` raw, `_t` trimmed, `_p` processed), music, sound effects |
| `public/imagery/` | Real Sentinel-2 crops from the app |

## Regenerate the audio (optional)

You only need this if you change the script. It requires Python 3 with `numpy` and `Pillow`, `ffmpeg` on the PATH, and an OpenRouter key in `OPENROUTER_API_KEY` or in `video/.env`. The key is git-ignored and never committed.

```bash
python tools/vo.py        # narration: google/gemini-3.8-flash-tts, voice Charon, one clip per line
python tools/music.py     # score: google/lyria-3-pro-preview
python tools/sfx.py       # synthesised whoosh, riser, impact, hit, blip, film grain
python tools/timeline.py  # trim + process each line, then write src/timeline.json
```

Mixing notes:

- The music ducks under the narration. Lines less than about 1.3 s apart count as one window, so the music doesn't swell between sentences.
- The score's silence-then-hit is aligned with the logo reveal.
- The final master was normalised to about −15 LUFS with a fixed gain and a peak limiter. Dynamic loudness normalisation lifts the ducked music back up, so it isn't used.
